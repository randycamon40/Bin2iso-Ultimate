📖 Panduan Penggunaan

📀 BIN → ISO

Konversi file disc image BIN (raw 2352 B/sector) menjadi ISO standar (2048 B/sector).

  • Upload .bin — bisa multiple sekaligus
  • Jika ada .cue, upload bersamaan agar mode terdeteksi
  • Mode Auto = deteksi dari sync pattern

💾 ISO → BIN

Konversi ISO standar menjadi BIN raw dengan ECC akurat.

  • Mode 1: sync + header + data + EDC + ECC
  • Mode 2 Form 1: + subheader, kompatibel PS2

🎵 Audio Extraction

Ekstrak track audio (CD-DA) dari BIN multi-track menjadi WAV.

  • Butuh file .cue + .bin berpasangan
  • WAV output: 44.1 kHz, 16-bit, stereo

⚡ Opsi Lanjutan

  • Hash: hitung MD5 & SHA-1 hasil untuk verifikasi
  • Verifikasi: cek integritas file hasil konversi
  • ZIP: export batch ke file ZIP tunggal
  • Skip ECC: konversi cepat tanpa ECC (kurang akurat)

💡 Tips

  • File besar (> 2 GB) sebaiknya diproses satu per satu
  • Untuk PS1, gunakan Mode 1
  • Untuk PS2, gunakan Mode 2 Form 1
  • Hasil konversi otomatis terunduh ke folder Download
